Operation – Wild Run

Behind the build

Gameplay systems

What I built

  • Three-lane movement with jump and slide actions; collider and animation state change with the move.
  • LevelGenerator advances track chunks, while Chunk builds obstacle encounters and carries reachable safe lanes between rows.
  • DistanceManager feeds run progress into speed and hazard difficulty, and saves the best distance.

Challenge

Keep the obstacle route readable as difficulty rises. Route generation carries safe-lane choices forward and increases hazard chances with distance.
